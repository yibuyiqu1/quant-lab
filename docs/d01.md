## 一、我学到的核心概念（用自己的话写）

1. **收益为什么不用价格**：价格不可比也不平稳；赚到的是变化，所以要先转成收益率。
2. **对数收益**：`ln(P_t) - ln(P_{t-1})`。好处是**多期可加**（3 天 = 3 天对数收益之和），
   简单收益必须连乘。所以研究里用对数收益，组合加权用简单收益。
3. **年化波动**：日标准差 × **√244**（不是 ×244）。因为波动随时间按 √t 增长。
4. **最大回撤**：分母是**该时刻之前的历史最高净值**，不是买入价、也不是期末最高点。
   公式 `nav / nav.cummax() - 1` 取最小值。它回答"最惨时你要忍受多少"，
   比夏普更接近"策略能不能被执行"。
5. **峰度**：pandas 的 `r.kurt()` 返回**超额峰度**（正态 = 0），`+3` 才是通常说的峰度（正态 = 3）。
6. **肥尾**：极端行情的实际频率远高于正态预测。这是 Day 1 最重要的结论。

## 二、实测数字（可复现，SEED=42）

| 指标 | 数值 |
|---|---|
| 样本天数 | 6002（差分后第一个是 NaN，被丢掉） |
| 年化收益 | **1.93%** |
| 年化波动 | **24.27%** |
| 夏普（无风险利率取 0） | 0.079 |
| 最大回撤 | **−75.23%**（2008-11-04） |
| 偏度 | −0.38（左偏，暴跌比暴涨极端） |
| 峰度（原始） | **7.695** |
| 日胜率 | 51.88% |
| \|z\|>3 实际 vs 正态 | **1.7827% vs 0.2700%**，**6.6 倍** |
| \|z\|>5 实际 vs 正态 | 0.2499% vs 0.000057%，约 4400 倍 |
| \|z\|>3 出现次数 | 107 次 / 6002 天 ≈ **平均 56 天一次** |

**一个有意思的发现**：±1σ 区间内实际占比 77.92%，正态只有 68.27%。
说明分布是"**中间比正态更集中 + 两端更厚**"——这就是"尖峰肥尾"的字面含义。

## 三、三句话结论

1. 沪深300 日对数收益的峰度是 **7.695**，正态应为 3 —— **尖峰肥尾**。
2. |z|>3 的实际占比 **1.7827%**，是正态理论 **0.2700%** 的 **6.6 倍**。
3. 因此后续因子检验**不能假设正态**，要用 bootstrap 或稳健统计量。

## 四、我的卡点与教训

| 卡点 | 原因 | 教训 |
|---|---|---|
| 运行脚本毫无反应 | 删掉了 `if __name__ == "__main__":` 入口 | 静默失败最危险；先查有没有真正**调用** `main()` |
| `TypeError: 'set' object is not subscriptable` | `{"键", 值}` 用逗号 → 创建的是 set 不是 dict | 字典用**冒号**分隔键值 |
| json 序列化报错 | numpy 类型不能直接存 JSON | 返回值包一层 `float()` |
| `pd.Seriers` 拼写错 | 定义时不报错，调用时才炸 | 看 IDE 的红色波浪线 |
| `r.mean` 漏括号 | 拿到的是"方法对象"不是数值 | 报错里出现 `<bound method ...>` 就是这个问题 |
| `r.std(off=1)` | 参数名错 | 记不准就 `help(pd.Series.std)` |
| 把 PowerShell 命令粘进 Python | 提示符是 `>>>` | `exit()` 退出后再敲命令 |
