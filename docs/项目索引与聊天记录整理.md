## 7. 运行环境排错

**你的问题**：`& E:/work/anaconda/python.exe ...` 报 `SyntaxError`；为什么写 `raise SystemExit(main())` 而不是 `main()`？

**答案**：
- `SyntaxError` 的原因：**把 PowerShell 命令粘进了 Python 交互环境**（提示符是 `>>>`）。
  `&` 是 PowerShell 的调用运算符，Python 不认识
- **VS Code 默认选中了 Anaconda**（它没装 akshare）→ 我加了 `.vscode/settings.json` 钉死 `.venv`
- `main`（不带括号）只是"提到函数"，**不执行** —— 这就是运行没反应的原因
- `raise SystemExit(main())` 的作用：把返回值当**进程退出码**交给系统，
  这样自动化脚本能判断成功与否（实测退出码 = 0）
- 副作用：字符串里有 Windows 路径要加 `r` 前缀，否则 Python 3.12 报 `invalid escape sequence`

完整排查见 [VSCode运行代码-排错手册.md](VSCode运行代码-排错手册.md)
