2 · pandas 核心操作（一张表记住）

想做的事写法要点
看数据df.shape / dtypes / head() / describe()每次分析先做这步
选一列 / 多列df["close"] / df[["close","volume"]]前者 Series，后者 DataFrame
按标签 / 位置选df.loc[行, 列] / df.iloc[行号, 列号]赋值一律用 .loc
筛选df[df["close"] > 4000]多条件用 & |，每项加括号
派生新列df["ret"] = np.log(df["close"]).diff()先 log 再 diff = 对数收益
昨日值df["close"].shift(1)shift 是时序对齐的核心
滚动统计df["close"].rolling(20).mean()前 19 行必为 NaN
分组压缩groupby("date")["x"].agg(["mean","std"])每组一个值
分组回填groupby("date")["x"].transform(lambda s:(s-s.mean())/s.std(ddof=0))横截面标准化必须用 transform
条件赋值np.where(cond, a, b) / np.select([c1,c2],[v1,v2],default=v0)不要写 if 循环
分层pd.qcut(x.rank(method="first"), 5, labels=["Q1".."Q5"])重复值多时必须先 rank
时间重采样s.resample("ME").last() / .pct_change()分组用 s.groupby(s.index.year)
排名df.groupby("date")["f"].rank(pct=True)分层回测的输入

核心心法：能让操作作用于整列，就不要逐行循环。实测 20 万次运算：for 循环 0.060 秒 vs 向量化 0.001 秒 = 63 倍。
