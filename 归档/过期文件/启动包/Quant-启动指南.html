01环境搭建

一次性做完，之后两个月不再为环境问题分心。

pip install uv
uv venv ~/.venvs/quant --python 3.11
source ~/.venvs/quant/bin/activate      # Windows: .venvs\quant\Scripts\activate

# 2) 核心依赖（第一周只装这些，别一次装全）
uv pip install pandas numpy scipy statsmodels scikit-learn
uv pip install akshare baostock matplotlib plotly jupyterlab

# 3) 后续再装（第二周起）
uv pip install alphalens-reloaded empyrical quantstats pyportfolioopt

⚠ 注意：alphalens 原版（Quantopian）已基本停止维护，在 Python 3.11 上易报依赖错误； 建议直接用社区维护的 alphalens-reloaded。若装不上，不要卡住—— 第一周的因子分析完全可以自己写 20 行 IC / 分组收益代码，反而理解更深。

02四周启动计划

每周一个明确交付物。没有交付物的一周 = 白过的一周。

阶段做什么交付物（验收标准）
第 1 周
工具链		 环境搭建；用 pandas 重写一遍「收益率 / 波动率 / 夏普 / 最大回撤」的计算； 手写一个 50 行内的向量化回测循环（不借助框架）。 一个 metrics.py，能用随机数据算出正确的夏普与最大回撤。
第 2 周
因子入门		 精读《因子投资：方法与实践》第 1–3 章；下载并清洗 A 股日线；计算 20 日动量与市值因子； 算 IC（Spearman）、画分组净值曲线。 一张 5 分组累计净值图 + 一张 IC 时间序列图。能说清 IC 为什么这么低。
第 3 周
体系化		 补齐价值（BP/EP）、波动率、换手率因子；做因子正交化与共线性检查； 读 López de Prado 第 7 章（交叉验证陷阱）。 4 个因子的 IC 汇总表 + 相关系数矩阵。能指出哪两个因子高度冗余。
第 4 周
第一个完整项目		 把 4 个因子合成复合打分，做行业市值中性化，加入双边千三的交易成本， 跑样本内 / 样本外（按时间切分）对比。注册 BRAIN 并提交第一个 Alpha。 一份 8–12 页的研究笔记（PDF）：数据、因子定义、方法、结果、失败原因分析。

Yves Hilpisch。把 Python 数值计算、随机过程、衍生品定价、投资组合一套打通。 作为「工具书 + 代码范本」使用，不必通读。

07第一个项目的标准流程

照这个顺序做一遍，你就拥有了一个能写进简历、能讲给面试官听的完整案例。

# 单一因子研究的七步标准动作（以 20 日动量为例）

1. 取数     → 30~500 只股票 × 3~10 年 前复权日线（务必前复权，且剔除停牌/ST/上市不足 60 日）
2. 定义因子 → momentum_20 = close[t] / close[t-20] - 1
3. 定义收益 → fwd_ret_5 = close[t+5] / close[t] - 1   # 注意 t+1 开盘成交，别用收盘价成交（未来函数）
4. 预处理   → 去极值(winsorize 3σ) → 标准化(z-score) → 行业市值中性化
5. 单因子检验 → IC / RankIC 序列、ICIR、t 检验、5 分组单调性、多空净值
6. 稳健性   → 换参数(10/20/60日)、换股票池(沪深300/中证500)、换时间段 → 看结论是否还成立
7. 加成本   → 双边千三（佣金+印花税+冲击）后重算 → 90% 的"好因子"会在这里死掉
验收标准：不要求因子有效——事实上第一次做出来无效才是正常且有价值的结果。 真正的交付物是一份说清楚了「数据怎么来的、因子怎么定义的、为什么失效」的研究笔记。 面试官更看重你是否知道自己在做什么，而不是曲线好不好看。

08五个坑，现在就记住

01 未来函数

用当日收盘价生成信号、又用当日收盘价成交；或用含未来的财务报表数据。 这是最致命也最常见的错误，回测再漂亮都是幻觉。

02 忽略交易成本

A 股双边成本（佣金+印花税+冲击）对短周期策略是致命的。 不计成本或按万分之一算，实盘一跑利润全被磨掉。

03 过拟合

参数、时间段、股票池来回调，总能调出好看曲线。 判据：参数尽量少；逻辑先成立（为什么动量会有溢价），数据才作数。

04 照搬美股因子

A 股有 T+1、涨跌停、印花税、股指期货基差、融券约束、小市值效应。 直接搬海外因子大概率失效，必须做本土化检验。

05 卡在装包上

环境报错、库装不上就停摆。原则：装不上就自己写 20 行替代， 先推进度。工具是手段，不是目的。

附：一条硬性原则

任何结论都必须有样本外验证。按时间切分（而非随机切分）， 并在验证集与训练集之间留出 embargo 间隔，防止信息泄漏。
